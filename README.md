# うたの手帖 — トピア楽曲使用報告

トピアの使用楽曲報告を補助する個人用Webアプリです。初回は公式サイトで作品情報を手検索し、持ち曲に登録します。

## GitHub Pages
Settings → Pages → Build and deployment で、Source を Deploy from a branch、Branch を main、フォルダを /(root) にして Save。

## 使い方
1. 設定でユーザーID・ニックネームを保存。
2. 曲を登録。JASRAC作品詳細のWeb Clipperコピーを貼り付けて入力補助を使えます。
3. 曲を選び、利用日・回数を確認して公式フォームへ移動。最後の送信は公式フォームで行います。

「続けて申請」は常に「いいえ」。登録情報はブラウザ内に保存され、GitHubには送信しません。サイトURL・ブラウザを変える場合は、旧サイトの設定から書き出し、新サイトで読み込んでください。バックアップにはID・名前も含むので公開リポジトリに入れないでください。

初回の公式検索は手動です。検索サイトの自動取得や外部APIは使用しません。管理状況は公式サイトで確認してください。

## 開発
HTML・CSS・JavaScriptのみ。ビルド不要。`node --check app.js` と `node tests/clip-parser.test.cjs` で確認できます。

非公式の入力補助ツールです。フォーム変更時は app.js の設問IDを更新してください。
